# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Contributors and maintainers are expected to follow its standards in project spaces and when representing the project.

Thomas Lothian is responsible for enforcement. A private conduct-reporting address is **TBD**. Until one is published, use a private GitHub message to the maintainer where available; do not post sensitive conduct reports in public issues. Security vulnerabilities use the separate process in [SECURITY.md](SECURITY.md).
