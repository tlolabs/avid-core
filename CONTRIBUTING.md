# Contributing

Outside contributions are welcome. Open an issue for significant API changes before implementation. Keep changes scoped to the shared library; host application packaging and UI behavior belong in ATIV or EnCAP. Run the checks in [docs/TESTING.md](docs/TESTING.md) and update relevant documentation and licensing notices.

Contributions must be legally compatible with GPL-3.0-or-later. Add a `Signed-off-by:` trailer to each contributed commit to certify the [Developer Certificate of Origin 1.1](https://developercertificate.org/). Cryptographic commit signing is recommended but is not required for normal contributions. Do not add vendored or copied code without clear origin and license information.

Thomas Lothian is the sole maintainer and final release authority. Outside pull requests are reviewed before merge.
