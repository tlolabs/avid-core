# Licensing and provenance review

Reviewed 2026-09-24 for the **AVID Core repository**, the source-code library consumed by ATIV and EnCAP. The conclusion applies to the code in this repository and source releases from it. Each consuming application's installer, runtime and code-signing eligibility need their own package audit.

## GPL-3.0-or-later decision

`src/`, `examples/`, and the test code were committed in AVID Core by Tom/Thomas Lothian. The incorporated EnCAP source identified in [docs/provenance.md](docs/provenance.md)—`crates/encap-video/src/lib.rs`, `crates/encap-ffmpeg/src/lib.rs`, and video state in `crates/encap-core/src/model.rs` at [`a96978e`](https://github.com/tlolabs/encap/commit/a96978e5bb89189b944e5dd6a30e5ee7e8fe28d4)—also has only Tom Lothian in its path history. The ATIV-origin inputs at [`2c5eeed`](https://github.com/tlolabs/ativ/commit/2c5eeed27e48d67fed128a62ff74dab6f00c2a82) were already GPL-3.0-or-later. EnCAP itself declares GPL-3.0-only; that earlier nonexclusive grant and prior AVID Core releases remain valid. Thomas, as the identified copyright holder, can grant **this AVID Core version** under GPL-3.0-or-later without relicensing the separate EnCAP repository. The [GNU GPL FAQ](https://www.gnu.org/licenses/gpl-faq.en.html#ReleaseUnderGPLAndNF) confirms that a copyright holder can issue different nonexclusive licenses for their own work. No other human author appears in the AVID Core Git history or the histories of those EnCAP source paths. This evidence supports the change requested by the owner; Git metadata alone cannot prove the absence of an unrecorded third-party rights claim.

`Cargo.toml`, the README, and selected original source headers now declare `GPL-3.0-or-later`; `LICENSE` contains the unmodified official GPLv3 text. The declaration covers **AVID Core-owned code**, not independent third-party crates, externally supplied FFmpeg executables, or applications that consume the library. The EnCAP repository's own GPL-3.0-only declaration is unchanged. Copyright notice: Copyright © Thomas Lothian.

## Inputs and redistributed material

The published crate is source only. `Cargo.lock` fixes 27 packages including AVID Core. Direct dependencies are `serde`, `serde_json`, `tempfile`, and `same-file`. Offline Cargo metadata reports a license expression for every package; all third-party packages offer a GPLv3-compatible MIT, Apache-2.0, Unlicense, or suitable permissive option, with exceptions and Unicode terms recorded in the [dependency inventory](docs/dependency-inventory.json). Exact versions and sources are in `Cargo.lock`. `docs/DEPENDENCIES.md` explains their roles; `THIRD_PARTY_NOTICES.md` preserves attribution and license boundaries. No vendored third-party source, Microsoft binary, font, or third-party artwork is a runtime component. The crate does include five small synthetic audio/image test fixtures under `tests/fixtures/ffmpeg/`, generated locally from FFmpeg sine and color filters; [their provenance record](tests/fixtures/ffmpeg/provenance.json) gives exact commands and hashes. The other JSON, graph, shell and C fixtures are original test inputs described in [source provenance](docs/provenance.md).

FFmpeg and ffprobe are **separate host-supplied processes**, not linked or bundled by this crate. AVID Core verifies executable paths/version identity and invokes them for media work. Their actual licenses depend on the binaries that ATIV or EnCAP chooses to build and distribute. Historical FFmpeg research under `docs/ffmpeg/`, `scripts/ffmpeg/`, and `runtime/ffmpeg/` is not part of the `Cargo.toml` crate package (`exclude` list) and does not turn AVID Core into an FFmpeg distributor.

The [GPLv3 System Libraries exception](https://www.gnu.org/licenses/gpl-3.0.en.html) and SignPath's identically named but independently administered [policy exception](https://signpath.org/terms.html) answer different questions. Source licensing, a consuming application's combined executable, redistribution of a Microsoft runtime beside that executable, and SignPath Foundation eligibility must be decided separately. No proprietary Microsoft component in this repository prevents licensing AVID Core-owned code GPL-3.0-or-later.

## Release format

AVID Core is a library, so its release is a tagged source revision and, if desired, a crates.io source package. It does not require a portable Windows ZIP, installer, Windows App SDK runtime, or code signing of an application binary. Host applications own those choices. A future AVID Core binary release would require a new exact-file inventory and licensing assessment before any SignPath claim.
