# Security policy

The current `0.3.x` source line is supported. Older releases receive fixes at the maintainer's discretion. Security fixes are published as tagged source updates and documented in the changelog.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/tlolabs/avid-core/security/advisories/new). Please include a minimal reproduction, affected revision, impact and any proposed fix. Do not open a public issue with exploit details before coordinated disclosure. The public project/security email is **TBD**; no substitute address is designated.

Thomas Lothian will acknowledge and triage private reports, coordinate a fix and publication with the reporter, and credit the reporter if requested. The exact disclosure date depends on the issue and fix readiness.
