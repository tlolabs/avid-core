# Support

- Report reproducible bugs with [GitHub Issues](https://github.com/tlolabs/avid-core/issues).
- Request features or ask usage questions in [GitHub Issues](https://github.com/tlolabs/avid-core/issues).
- Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/tlolabs/avid-core/security/advisories/new), as described in [SECURITY.md](SECURITY.md).

AVID Core is a library; ATIV and EnCAP application-specific support belongs in their own repositories.
