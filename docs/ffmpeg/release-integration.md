Workflow dispatch is a preflight and cannot publish. Existing published releases are rejected rather than overwritten. The current consumer contract requires one complete six-target manifest and verified GitHub provenance; do not publish a partial runtime until all consumers support it. The draft is not completion.

Use EnCAP equivalently. The importer verifies exact app/workflow/run/job/artifact identity and package hashes, without changing any unperformed signing or upgrade check.

No external signing credentials or services are changed by this repository policy.
